A Claude Code skill that automates subscription cancellation. It reads credit card statements, extracts active subscriptions, asks clarifying questions, and then automatically opens Chrome to cancel selected subscriptions.

## Key Features
- Parses credit card statements to identify subscriptions
- Interactive follow-up questions to confirm cancellations
- Automated Chrome browser control for actual cancellation
- Saves users time and money on unwanted subscriptions
