Remotosh is a terminal streaming tool that lets you access your terminal from your phone via QR code. Stream long-running builds and monitor terminal output remotely without being stuck at your desk.

## Key Features
- QR code based connection to your phone
- Real-time terminal streaming
- Perfect for monitoring long-running builds
- Works with any terminal (installed via `npx remotosh`)
- Mobile access to terminal output

## Use Cases
- Monitor builds while away from desk
- Check long-running processes remotely
- Keep tabs on deployments or database operations
- Perfect for taking breaks while builds run
