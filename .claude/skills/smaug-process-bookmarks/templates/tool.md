# Tool Template

Use for GitHub repositories filed to `./knowledge/tools/{slug}.md`

```yaml
---
title: "{tool_name}"
type: tool
date_added: {YYYY-MM-DD}
source: "{github_url}"
tags: [{relevant_tags}]
via: "Twitter bookmark from @{author}"
---

{Description of what the tool does, key features, why it was bookmarked}

## Key Features

- Feature 1
- Feature 2

## Links

- [GitHub]({github_url})
- [Original Tweet]({tweet_url})
```

## Field Notes

- `title`: Repository name (e.g., "whisper-flow")
- `source`: Full GitHub URL
- `tags`: Extract from repo topics, language, or infer from description
- `via`: Twitter handle who shared it
- Description: Summarize README or repo description, focus on what it does
